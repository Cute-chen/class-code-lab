# 代码创作实验室开发与验收记录

## 已完成

- MySQL 自动建库、GORM 迁移和首次教师账号。
- 数据库会话、HttpOnly Cookie、登录限速和首次强制改密。
- 班级一级隔离、教师授权、本班广场和跨班精选。
- Excel 名单导入、单个学生添加、密码重置、账号与 AI 状态管理。
- 单作品草稿、自动保存、历史版本、恢复、发布快照和再次发布。
- OpenAI Chat Completions 兼容网关，支持 SSE、普通 JSON、用量记录、429/5xx 单次重试和未配置降级。
- AI 对话、完整 HTML 提案识别、安全检查和学生确认应用。
- 独立 Runner、五分钟运行令牌、sandbox、CSP、权限策略和运行错误回传。
- 教师课堂总览、作品管理、安全预览、AI 用量/对话、班级设置和操作记录。
- 学生工作台、本班广场、跨班精选和单作品体验页。
- 班级作品评分额度、实时积分分配、排行榜和冠亚季军展示。

## 自动化验证

- 安全检查允许普通函数和固定版本 CDN。
- 拒绝 fetch、外部跳转、动态字符串执行和浮动 CDN 版本。
- Chat Completions SSE 增量解析和 Token 用量解析。
- 兼容供应商普通 JSON 响应。
- 429/临时错误重试一次，401 鉴权失败不重试。
- 未改密账号不能进入工作区。
- A 班不能读取 B 班普通作品，精选作品例外。
- 草稿修改不影响已发布快照。
- 危险草稿不能创建预览令牌。
- 过期 Runner 令牌被拒绝，合法响应包含严格 CSP。
- 教师授权表和作品广场联表字段映射回归测试。
- 历史版本只保留最近 30 份。
- 评分额度限制、自评与跨班拦截、排名破同分、撤下或锁定自动退分。
